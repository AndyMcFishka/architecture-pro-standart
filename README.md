# architecture-pro-standart

Проектная работа третьего спринта: цифровая трансформация банка «Стандарт».

- `Task1` — карта IT-ландшафта и схема интеграции приложений.
- `Task2` — требования FURPS+.
- `Task3` — ADR открытия депозитов онлайн.
- `Task4` — ADR передачи ставок в кол-центр, задачи и RoadMap.
- `Task5` — ADR подачи заявки на кредит онлайн.

Решения выполняются в ветке `solution` и сдаются через pull request в `main`.
